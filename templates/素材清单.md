# 素材清单（**采集者自己用的检查表**）

> ## ⚠️ 这份东西**不要再拿去问使用者**（2026-09-27 改，依据：一位真人的反馈）
>
> **它的用途变了。** 原来它是"发给使用者、让他逐类勾"的**入口**；
> 现在它是**采集者手里的检查表**——**末了拿它对一遍，看有没有漏掉一整片关于他的东西。**
>
> **为什么改**：真人原话——
> 「**为什么要问别人有没有这些东西呢**……我一直以为**你在做访谈判断他的特质**」。
> 这句话点破了它：**判断特质靠访谈，素材的职责是交叉验证**。
> 我把它当成了入口，**而且是最难、最劝退的那一环**——它要求人先翻自己的箱底。
>
> **入口改成了什么**：见下面的「第 0 步 · 怎么开口」。**入口只有一小块，而且能整块跳过。**
>
> ★ **旧做法（逐类勾）唯一的适用场合**：使用者**明确说"我愿意逐类过一遍"**。
> 否则**不要**主动发这份清单给他——**换成聊天、选择题、或者直接由你去取。**

---

## ★ 第 0 步 · 怎么开口（**入口，最要紧的一节**）

### 六条原则（2026-09-27，全部来自真人反馈，不是设计推测）

| # | 原则 | 出处（原话） |
|---|---|---|
| **1** | **需要什么再问什么**，不预先盘问 | 「**你需要什么再问什么最好**」 |
| **2** | **入口要小**，允许残缺就开始 | 「各种设置能少问就少问」 |
| **3** | **能选就别打字**（选择题优先） | 「用选择题的方式**尽量减少别人打字的频率**」 |
| **4** | **开口前先给信任**：让他先查你 | 「先跟他们说你值得信任，**让他们主动检查你的安全性**」 |
| **5** | **素材由你去取**，别让他翻 | 「你就让他们用自己的 agent 检查就行」 |
| **6** | **只问会改变下一步的问题** | （对照 `goutoujunshi`：「只追问 1–3 个真正影响决策的问题」） |

> ★ **这六条如果早写在开头，整轮返工都不会发生。**
> 之前的版本把力气全花在"21 类怎么写"上，**而真正的瓶颈是"怎么开口"**。

### 三条"自然"的做法（不要盘问）

**① 让他讲故事，别让他填表。**
故事是人的本能，清单不是。**说一件事，我能从中读出好几样**——他不用回答五个问题。

**② 不让他"写"，让他"改"。**
> **我先猜一个，你纠正我。**
**纠正比创作容易得多**，而且自带尊重：我先把理解摆出来，你否决它。

**③ 不开口也能拿到的，就别开口。**
**观察 > 提问。** 有授权时，**直接看比问准、也比问多**。

### ★ 入口模板（照这个开口，**只有一小块，可以整块跳过**）

> 我大概知道我该做什么——给我一点东西，让那个小伙伴像你，而不是像个客服。
>
> **不用准备，也不用整理。怎么方便怎么来：**
>
> **① 你要是想省事**，就直接跟我说说最近在忙什么、烦什么，随便聊。**我从对话里自己捡。**
>
> **② 你要是想快**，就选一下（选完就行，不用解释）：
> - 你最想让它帮你做什么？ **A 陪你 / B 催你干活 / C 记你的作息 / D 帮你攒钱 / E 别的**
> - 你平时在哪台机器上待得最久？ **A 这台电脑 / B 手机 / C 都有，说不清**
> - 你想让它长什么样？ **A 桌面上的小东西 / B 手机里能聊的 / C 还没想好，你给几个我看**
>
> **③ 你要是懒得打字**，那这样：**你随便扔个东西给我**——一张截图、一段你写过的字、一个你做过的东西。
> **我看完了说我的判断，你只负责说"对"或"不对"。**
>
> **以上三条挑一条就行，剩下的以后慢慢补。答不上来的全部留空。**

> ★ **注意这一版入口里，21 类一个字都没出现。** 这是刻意的。

### ★ 选择题的四条纪律（**别用坏**）

选择题很好用，但用坏了会**替人回答**：

1. **选项要覆盖常见情形，但必须留出口**——最后一个选项永远是
   「**E 以上都不是 / 我说不清**」，**不许逼他二选一**。
2. **只对"事实型"问题用选择题**（在哪、多久一次、要不要）。
   **"为什么""那阵子什么感觉"这类，不给选项**——给了就变成引导。
3. **选择题拿到的信息比打字浅**。所以它用来**开局、降低门槛、确认**，
   **不用来挖驱动模型**。
4. **他打字多的那几轮要珍惜**：他愿意展开的地方，**就是他在乎的地方**，
   那几句往往比整张清单都值钱。

### 只问"会改变下一步"的问题

**每轮最多 1–3 个。** 其余的一律记进「待补」，**下一轮再说**。

> ★ **这一条是从 `goutoujunshi` 学来的**（它的"每次分析"第 5 条：
> 「只追问 1–3 个真正影响决策的问题」）。
> **它敢少问，是因为它每轮都在攒**（「后续沿用已知信息，只补问会改变建议的变化」）。
> **本 skill 原来没有这个机制——是一次性采集。**
> → 所以从 2026-09-27 起：**采集也改成分批攒，不再一次问完。**

### 先给东西，再讲道理

`goutoujunshi` 的做法是「用户只要一句回复时，**第一屏先给一条可复制成品**」。
本 skill 一样适用：**先给一版能看的，再问他哪里不对**——**不要先问一堆，什么都不给。**

## 以下是检查表本体（采集者用，别当问卷发）

> **用法**：把下面 **21 类、分 6 组**分批发给他（**每轮上限 3 类**，别一口气全抛），让他勾「有 / 没有 / 不确定」。
> ⚠️ **"按组分批"不等于"一个组发一批"**——各组大小差很多（A 组 2 类、B 组 7 类、C 组 3 类、
> C2 组 4 类、D 组 3 类、E 组 2 类），**组内还要再切**。
> **不要用开放式的「你手上有什么材料」代替这一份**——实测那样会答不全，而且他不知从哪说起。
>
> **每一类都给了例子**：例子不是让你照着找，是让他**认得出来**自己那堆东西算哪一类。
>
> **⚠️ 勾完必须做最后的第 ⑲ 步（清单外还有什么）** —— 清单会变成新的天花板，这一步是唯一解药。

## ★★ 第 0 步（**在问任何问题之前**）：先让他查你，再问他能不能看电脑

> **这一步是 2026-09-27 由一个真人提出来的，原话：**
> 「你先跟他们说你值得信任，**让他们主动检查你的安全性**，再向他提出看电脑。」
>
> **为什么要这个顺序**：这本 skill 的铁律四是「**验证优先于声称**」——
> 那它对使用者也不能例外。**"请你相信我"必须先变成"你可以先验我"，才有资格往下谈。**

**照这个顺序做，别跳：**

1. **先自报边界**（一句话说清你**会**碰什么、**明确不碰**什么）：
   > 「我要看的话，只看**文件名、类型和日期**，用来判断"这一类你有没有"。
   > **不读内容**；**不碰**：别人的聊天记录、家人与工作往来的东西、密码与账号文件。
   > 找到什么我都**只报给你**，你自己决定留不留。」
2. **让他用自己的 agent 查你**（不是让他信你）：
   > 「**你可以先让你自己的 agent 检查我**——看我到底能读哪些目录、有没有联网、
   > 干不干净。查完你再决定要不要让我看电脑。」
   > ★ 这一步**不需要你提供任何工具**：他手上那个 agent 本来就有这个能力，
   > **你只要主动把这句话说出来**。
3. **然后才问"这两条路你选哪条"**：

| 路子 | 怎么说 | 代价 |
|---|---|---|
| **A 你自己过一遍** | 把清单发给他，他逐类勾 | 准，但要他花时间 |
| **B 我去你电脑上对一遍** | 「我按这 21 类去你电脑上过一遍，把找到的报给你，你过目确认」 | 省事，但**必须他先授权、且结果必须经他确认** |

> ★★ **为什么要给 B 这条路**（实测教训，来自同一个真人）：
> 他原话是「**有，因为我懒，相信大部分人都这样**」。
> **不许把"逐类翻找"的活儿全丢给使用者。** 只给 A 一条路，
> 结果就是他在被问到的第一秒去找捷径，或者干脆不做了。
> ★ **但 B 有个不可替代的前提**：**"这算不算我的"仍然只有他能定**——
> 所以 B 的产出是**"我找到这些，你看哪些算"**，不是"你有哪些材料"。

**★ 哪些类能走 B、哪些必须开口问本人**（走 B 时照着这张表）：

| 能代查（B 可以覆盖） | **必须问本人**（B 永远查不到，别用搜索冒充） |
|---|---|
| 6 工程/项目目录、10 作品、7 自建工具 | **9 参照系 / 核心恐惧 / 家庭影响** |
| 4 笔记库、5 工作区/AI会话、8 持续采集 | **10 禁区与授权**（什么话会让他不想继续聊） |
| 3 行为数据（有电子痕迹的那部分）、13 不在电脑上的（只能查明"有没有备份"） | **11 审美与作息**里的"典型一天""明知没用但留着的" |
| 17 旧版本/废弃副本、18 skill包、19 工作台 | **20 关系 / 说话方式 / 身心状态** |
| **20 职业轨迹**（简历、项目目录、求职记录能查） | ★ **说话方式**——它**只存在于他怎么说话里**，任何搜索都拿不到 |

> ★ **这张表里最要紧的一格是"说话方式"**：它是让 AI **说话像本人**的唯一材料，
> 而它**永远不在硬盘上**。**搜索省下来的力气，正好该花在这几类上。**

## ★ 开勾之前，先把这句话原样念给他听

> **「下面这些，只要是你反复做过、或者长期留着的，就先勾上。
> 别管它算不算『材料』，也别管它算不算『你的』——
> **上班干活用的也算，那是你花时间最多的地方。**
> 那两件事由我来判断，不由你。你只负责告诉我它在不在。」**

> ★★ **这句不是念一次就完事——第 6–8 类之间要主动再念一遍。**（2026-09-27 加）
>
> **实测：它是延迟生效的，代价是三轮。** 一位理发师的时间线：
>
> | 时点 | 她的反应 |
> |---|---|
> | 开勾前 | 念了判据，她没说什么 |
> | 第 3 类 | **没拦住**——她先自己降级（「就我上班用的」），**然后才小心地问「那个也算吗？」** |
> | 第 6 类 | **开始主动上交**——「（停一下）……**花钱买的课没看完，这也算啊。**」 |
> | 第 7–9 类开场 | 「**行吧，你说算就算。**」 |
>
> → **判据句要等三轮才真正被她接受。** 所以：
> **① 开勾前念一次；② 第 6–8 类之间（清单中段、连答"没有"最多的那一段）主动再念一次。**
>
> ★ **"上班用的"是最强的一条降级理由，必须点名拆掉**：
> 实测里被降级的东西有**一半是"给工作干的"**——
> 客户本（"记客户的"）、派件本（"我对账用的"）、记账（"为了算提成"）、
> 话术（"顺手的事"）……**它们全部先被归成"工作"，然后才被排除。**
> 而那些恰恰是**最硬的行为数据**（每天在写、写了几年）。
> → 所以判据句里**必须明说"上班干活用的也算"**。

**为什么必须先念这一句**（实测教训，不是设计推测）：

一个材料不多的人，真正的失败模式**不是「我什么都没有」，而是「我有的这些不算数」。**
实测里被采集的五个人，一律把自己有的东西**主动降级**：

| 他真正的说法 | 他其实有什么 |
|---|---|
| 「这不就是工作么」 | 写了两年多的记账本 |
| 「记我自己的事的地方？没有」 | 写满两本的客户记录本 |
| 「那不叫记录，那叫打游戏」 | 开服玩到现在、两年多没断的账号 |
| 「就是套模板，不算会设计」 | 帮人做过 5 张海报 |
| 「都是孩子」 | 按年份命名、坚持 6 年的成长相册 |
| 「谁没有」 | 8000 张照片 + 三年聊天记录 |

**注意：这五句里，只有两件是"东西形态和例子对不上"，其余全是"这算我的吗"。**
所以**光把例子写宽是没用的**——要解决的是**归属**，不是形态。

**遇到他说「这不算吧」「这也算？」时怎么接**：

- ✅ 「**算**。我说了算——先记下来，后面要不要用我来定。」
- ✅ 「**正因为你觉得它不算，它才值钱**——你觉得不算的东西，往往是你最自然的样子。」
- ❌ 不要顺着他说「那确实不算」。
- ❌ 不要追问他为什么觉得不算（那是要他自我审判，会把人推走）。

**另一个必须提前给的许可（防止他中途退场）**：

> **「中间会有连着好几类你都答『没有』，那是正常的，不代表你没东西——
> 那份清单是中段偏严，好东西大多在后半段。答『没有』完全没关系，接着往下走就行。」**

> ★ **这条实测救命**：有一次被采集者说「最想停在第 6 类那里……我有点想直接说
> 『我这些东西都没用，别做了』」，她最后留下来**靠的就是采集者即兴说了句
> 「说没有也没关系」**——而那句话**当时并不在流程里**。现在它在这儿了，**不许省**。

## 怎么勾

对每一类，让他选一个：

- ✅ **有** —— 并且**说出在哪**（路径 / 软件名即可，不用整理）
- ❌ **没有**
- ❓ **不确定** —— 记下来，后面一起查（**不确定 ≠ 没有**，别替他判）

## A 组 · 关于「他自己说过什么」

### 1. 深度访谈 / 一对一聊过自己的记录

**例子**：朋友或 AI 给你做过的访谈记录、心理咨询笔记、播客式自述、深夜长文、和 AI 的深度对话存档。

> 价值最高，也最容易自我美化。**有就优先用。**
> 注意：**和 AI 的长对话也是访谈**——它往往比正式访谈更真实，因为当时没打算给别人看。

### 2. 既有材料 / 为别的目的写过的东西（**短的、偶尔发的也算**）

**例子**：简历、求职信、面试复盘、工作总结、周报日报、个人陈述、申请文书、毕业论文致谢、
**朋友圈/社交平台发过的任何字**（**不必是长文**）、群里的汇报与通知、给别人的留言与说明。

> 局限是"为别的目的写的，有取舍"；价值是**能交叉验证访谈里的说法**。
>
> ★ **"长文"这两个字会漏掉一整片。**（2026-09-27 加）
> 实测里一位理发师答"这一类没有"的**同一句话里**说出了：
>
> > 「朋友圈我一年就发一条，过生日那天，**就一句话配张图**——**那也不算写啥吧**。」
>
> → **低频、极短、随手发的，当事人一律判成"不算写"。**
> 所以这一类**别让"长文"两个字当门**——**"你发过字没有"**比"你写过东西没有"好用。
> ★ 另：**交班汇报、群里报数、年底总结**这类"给单位写的"，当事人也常判成"不算"——
> **它们算**，而且往往比简历更能看出他实际在做什么。

## B 组 · 关于「他实际做了什么」（比自述硬）

### 3. 行为数据（**最不会说谎的一源**）

**例子**：手环/手表睡眠、手机"屏幕使用时间"、路由器设备上线时间、记账 app、支付账单导出、日历里的实际事件、IDE 编码时长统计、
**纸质账本与手写流水**、**备忘录里"一个月一条"的开销记录**、**工地/门店/柜台的手记**。

> **不用专门去记录**——你生活里已经在产生，只是没人汇总。
> **拿不到就算了**，不许为了凑三源编数据。
> ★ **不一定是电子设备产出的**：一支笔一个本子记了两年，是**同一类东西里最硬的那种**（实测：有人当场把自己的
> 纸记账本否掉，理由是"这不就是工作么"——**那是这一类里最值钱的样本，不是最没用的**）。
> ★ **也不一定是"记账"**：凡是**日复一日、有时间痕迹**的都算（排班、点货、接送、打卡、写了几页）。

### 4. 笔记库 / 第二大脑（**= 你记东西的地方，不分纸和电、不分记谁**）

> ⚠️ **类名的白话版就是这一句，连类名一起念给他听**：这个类名容易被读成"数字笔记软件"，
> 而**实测里三个人没有一个**把纸质本子归到这一类——**类名把例子压住了**。

**例子**：Obsidian / Notion / 语雀 / flomo / 印象笔记 / 飞书文档 / 备忘录 / 微信收藏 /
**纸质本子（错题本、摘抄本、工作手册、随身小本）** / 便利贴 / 台历上的字。

> **长期、自发、带时间戳** —— 人格是会变的，笔记库往往留着**变化轨迹**（"他半年前说想去大厂，现在说想稳定"比任何单次回答都说明问题）。
> 库大的话**先给地图，别整库读**。
>
> ★ **"写完了换下一个、旧的还留着"也算**——那正是"长期坚持"的证据，也是旧版本。
> ★ **别只问"用什么软件"**——不问"纸的有没有"，这一类会整块漏掉。

> ★★ **记别人的，只要也是你长期在写的，照样算。**（2026-09-27 加，修的是**修错的轴**）
>
> 实测教训：v1.9 以为这一类的失效轴是"**纸的 vs 电的**"，于是补了白话类名和"纸的也算"。
> 结果一位理发师**照样把两年多的客户记录本排除掉了**，她的原话是：
>
> > 「**记我自己的事的地方？没有。真没有。**」
> > 「那个客户本是记客户的，**你也说了不算这一类**。」
>
> → **真正的轴是"记别人的 vs 记自己的"，不是"纸的 vs 电的"。**
> 而"记别人的"那本子**恰恰是最硬的行为数据**（她两年多每天在写、写满两本）。
>
> **所以这一类的问法要拆成两个子项，各答一次**：
> 1. **记你自己的**：日记、备忘、想法、随手记
> 2. **记别人的 / 记活的**：客户本、通讯录备注、派件/点货/排班/账目、病例、学生名册
>
> ★ **第二项必需单独问**——不问，这一类就只收到"日记"，而**大多数人的本子记的都是活**。

### 5. 工作区 / 与 AI 的会话记录

**例子**：AI 助手的工作目录、历史会话、导出的聊天记录、各种 skill / 提示词 / 自动化配置。

> 记录的是一次次**真实决策过程**，比事后回忆准得多。

### 6. 工程 / 项目目录（**= 你一段一段做出来的东西，不一定是代码**）

> ⚠️ **类名白话版**：这一类**不是"程序员专用"**。实测里非技术背景的人一看到"工程"就整块跳过。

**例子**：代码仓库、STM32 / Arduino / 硬件工程、比赛作品、个人项目、设计文件、**图纸与 CAD**、
**课程作业与实训材料**、**长期维护的表格**（排班 / 库存 / 名单 / 报价 / 进出货）、
**做了一半停下来的东西**。

> 关键用法：`git log --date=short` 的日期分布 = **真实的坚持度**（哪天真的在写），
> 拿去对照访谈里"我最近很自律"这类说法。**这一条最常被跳过，因为没人觉得工程目录算"人格材料"。**
> ★ **没有 git 也能看坚持度**：表格里的修改日期、本子的厚度、文件的命名规则——
> **"他为一个东西维护了三年"这个事实本身**就是材料（实测：有人用 Excel 记了三年岗位与分数，
> 却答"不确定那算不算工具"）。
> ★ **"做了一半"的也算**，而且常常比做完的更有信息量（放弃点在哪）。
> **别在问的时候提"代码"两个字**——一提就把非技术的人筛掉了。

### 7. 正在跑的服务 / 自动化 / **他自己写的工具**

> ⚠️ **类名白话版**："**你有没有自己弄出来、一直在用的东西**"——
> **不限于代码，也不限于电脑**。实测里这一类的例子全是技术向（自启脚本 / 爬虫 / 看板 / 插件），
> 只用手机的人**一个都对不上**。

**例子**：自启脚本、定时任务、本地服务、爬虫、看板、桌宠、浏览器插件、命令行工具、自动化工作流、自己写的 skill 包、
**一个自己攒的表格/模板/清单**、**手机上的快捷指令**、**一套自己的排班或点货办法**、**常年用的手机闹钟组**。

> 说明**他实际在为什么花时间** —— 和他说的往往不一致，**不一致就是最有价值的发现**。
> 自己写的工具还多一层信息：**他选择把哪件事自动化**，暴露了他真正嫌麻烦/真正在意的环节。
> ★ **"我不觉得那算工具"是最常见的回答，也是最好的信号**——那说明它已经变成他的本能了。
> ★ **纸质/口头形态的"个人系统"也算**：一套固定话术、一个固定流程、一本固定记法的本子。

### 8. ★ 持续采集 / 订阅 / 情报流（**两个方向都算**）

> ⚠️ **这一类长期只问了一半。** 原版只覆盖"**他主动搭的采集**"（RSS / 简报 / 爬虫），
> 于是**"长期在接收"的人全部落空**——实测里有人手机里三个信息群、订了好几个号，
> 却因为"我没搭过什么东西"而勾了「没有」。

**两个方向，都要问**：

| 方向 | 例子 |
|---|---|
| **① 他主动搭的**（有产出） | RSS、每日简报、行业情报档案、竞品监控、自动抓取的任务、他自己维护的"每日情报"目录 |
| **② 他长期在接收的**（无产出，但**天天在**） | **长期在看的群**（行业群 / 岗位信息群 / 同行群 / 家长群）、**订阅号 / 邮件订阅 / 推送**、固定追的博主或UP主、每天必刷的某个板块 |

> **这一类的价值在于「他长期在追踪什么」** —— 而这个往往比任何单次访谈都更能说明他的方向。
> 记录要点：**追踪什么 / 什么频率 / 坚持了多久 / 为什么追踪 / 拿到之后怎么处理**。
> （"坚持了多久"尤其值钱：能坚持 40 天的信息流，和试了三天就停的，含义完全不同。）
> ★ **方向②不必"有产出"**：**"我天天看，但看完就忘"照样是材料**——
> 它说明**注意力长期流向哪里**，那本身就是信息。
> ★ 判断标准是**"他长期在看"**，不是**"他搭了什么"**。

### 9. 设备与屏幕使用数据

**例子**：主力机 / 备用机 / 平板 / 手机的型号与分工、哪块屏最常看、机器是否长期开机、是否远程使用。

> 直接决定阶段 3 的载体选型与阶段 5 的护屏方向。
> **本项目为"误判屏幕没人看"付过一次代价**（给没人看的屏把帧率拉满，随后全部推翻）。

## C 组 · 关于「他产出了什么」

### 10. ★ 作品 / 交付物

**例子**：简历（尤其**多版本**：通用版/诚实版/定向版）、PPT / 演示文稿、报告、论文、设计稿、发出去的仓库、发布的文章、课程作业成品。

> **这一类的价值是"他已经能把什么交出去"** —— 和能力自述对照会很有信息量。
> ⚠️ **多版本本身是重点**：如果同一份简历有"普通版"和"诚实版"，
> **那个差异就是他的自我认知边界**（哪部分他愿意写给别人看、哪部分只敢写给自己看）。
> 别只挑最完整的那版看，**把版本差异记下来**。

### 11. ★ 他做过 / 讲过的东西

**例子**：分享会/讲座（含讲稿与演示）、教别人的材料、发过的帖子、直播、答疑、给朋友解释过的东西。

> 区分点：**第 10 类是"交付物"，这一类是"输出行为"**——他**选择把什么讲给别人听**。
> 讲稿尤其值钱：**他为了讲清楚一件事，会把自己的方法整理成结构**，
> 那往往是他本人对"我是怎么做的"最清晰的一次表达。

### 12. 审美 / 素材 / 生活痕迹

**例子**：喜欢的界面截图、配色、海报、歌单、收藏夹、头像历史、明知没用但留着的东西、房间照片、
★ **按年/按主题长期整理的相册**（例："一年一个相册、按年份起名、已经六年"）、
★ **长期留着没删的照片集**、**实物照片或贴纸**、**工位/店面的照片**。

> L3 人设内容包里**至少五个模块**靠这一类吃饭（标签墙、人设卡片、头像风格、动物类比、24 小时彩蛋）。
> ★ **"按年份整理"这种"有规则的坚持"是这一类里最值钱的**——它同时说明了**审美**和**长期投入**，
> 但实测里当事人会把它判成"那不算啥，谁不给自己孩子拍照"。
> ★ **判定口径**：**只要他长期留着、并且会翻回去看，就算**——不必是"作品"。

## C2 组 · ★ **别只盯这台电脑**（新用户最容易全漏的一组）

> **这三类是拿一个真实的人做反向确认时挖出来的**——当时那份 15 类清单**一条都没覆盖**：
> 它默认"材料都是这台电脑上的文件"、默认"材料都是关于他自己的"、默认"材料都是做成了的东西"。
> **三个默认全是错的。**

### 13. ★ 不在电脑上的东西（纸质 / 手机 / 实物 / 别处）

**例子**：纸质笔记本、便利贴、打印件、手写稿；**手机备忘录/截图/录音/语音消息**；
奖状、作品实物、模型、拆过的东西、实物照片；**多个硬盘、网盘、旧设备**里没扫过的部分。

> **⚠️ 这一类的存在是一条系统性提醒**：会跑采集的人（尤其是 AI）**天然只看文件系统**，
> 所以"不在电脑上"的东西**永远不会被自动发现**，只能靠问。
> 拿到之后**先问一句"要不要数字化"**——不数字化也可以，**记下它在哪、有什么就够用了**。

### 14. ★ 别人眼里的你（外部校准）

**例子**：老师评语、作业批改、面试反馈、朋友/同事的评价、**聊天记录里你自己说过的话**、
**你为别人做的东西**（帮人写的、教的、做的）、别人给你的东西（信件/礼物/建议）。

> **为什么这一类关键**：前面所有类都是**自述或自证**，而自述会美化。
> **别人找你做什么，比你说自己擅长什么准。**
> ⚠️ **隐私边界**：只取**你自己说过的话和你自己收到的反馈**，
> **不要导出、不要分析别人的话**（那是别人的隐私，不是你的素材）。

### 15. ★ 放弃与纠结清单（"没有什么"也是材料）

**例子**：买了/开始了但**没坚持下去**的（课、会员、工具、项目）；
**反复纠结、至今没结论**的事；**避着不愿谈**的话题。

> **反面素材的价值被严重低估**：清单天然只问"你有什么"，
> 于是**你所有的失败、放弃、绕开的路全都不可见**——而它们往往比成果更能说明你。
> 「**放弃列表**」尤其有信息量：**他放弃过的方向，定义了他的边界。**
>
> 勾到"避着不愿谈的"**只需勾一下，不要追问**（详见 `references/1-采集与访谈.md` 的问法准则 4）。

### 16. ★ 旧物 / 舍不得扔的东西（**带年份的最好**）

> **这一类是 2026-09-27 由一个快递员在收尾时自己提出来的**，原话：
> 「加一条吧，**问手里有没有旧东西的**——旧票据、旧本子、坏了的玩意儿。
> 我们这种人手里都留着点，你说不要，舍不得扔。**我那纺织厂的牌子，二零零三年的，还在抽屉里。**」
>
> → **它是当事人自己交出来的清单缺口**（⑲ 步的真实产出），所以它的措辞照他的话说。

**例子**：旧票据、旧工牌/厂牌/学生证、过期证件、坏了的但没扔的玩意儿、
用旧了还留着的工具、旧车票/门票/收据、换下来的旧手机旧硬盘、孩子小时候的东西、
搬家时舍不得丢所以一直搬来搬去的那些。

> ★ **它和第 12、13、17 类相邻，但都不重合**——那三类问的是"要不要用"，
> **这一类的核心是"舍不得扔"。**
> ★ **"舍不得扔"本身是材料**：它说明他在乎什么、以及他为什么留着。
> 一个留了 20 年的工牌，比一句"我做过纺织工"有信息量得多。
> ★ **判定口径要松**：**不必有用途、不必有价值、不必完整**——
> 只要"你说不要，他舍不得"，就算。
> ★ **带年份的优先记**（"二零零三年的""搬家那年"）——年份是它最值钱的部分，
> 因为它把一段说不清的历史钉在了时间轴上。
> ★ **别劝人扔东西**，也别问"为什么留着"（那是要他自我审判）——**记下它是什么、哪年的，就够了。**
> ★ **拿到之后先问一句"要不要拍张照"**——不拍也行，**记下它在哪、是什么、哪年的，就够用了**。

## D 组 · 关于「坑」与「协议」（这一类必须单独勾）

### 17. 旧版本 / 已废弃的副本 ⚠️

**例子**：同一份文档的多个副本、"旧版""备份""最终版2"、别处的镜像、归档目录、`backup\` 里的历史快照。

> **这一类的存在本身就是信息。** 本 skill 的完整实例真栽过：
> 两份同源档案分叉（一份 v1.6、一份 v2.1），诊断直接跑偏，**浪费了一整轮**。
> **勾到这一类就当场做一件事：判定"以哪份为准"，写进台账。**
> 详见 `references/6-验证纪律.md` 的「两份副本」。
>
> **另外**：旧版本快照是**变化轨迹**的原材料（"他三个月前写的自己是这样的"）——
> **别急着删，先确认权威版本，再决定留不留。**

### 18. ★ skill 包 / 提示词库 / 可分发的东西

**例子**：自己写的 skill、提示词集、模板库、脚本包、给别人用的工具。

> 它同时是两样东西：**素材**（说明他关心什么、怎么组织知识）和**产出**（他已经能做成可分发的形式）。
> 如果里面有 `README` / `CHANGELOG` / `LICENSE`，**说明他已经有工程化习惯**——那部分本身值得采集。

### 19. 工作台 / 入口 / 暗号体系

**例子**：一个专门的"工作台"目录、固定的开场暗号（"加载人格""今日整理"）、交给 AI 的固定指令集、目录约定。

> 说明他**已经在用一套协议和 AI 协作**——那套协议是他反复迭代出来的，比临时指令可靠。
> 采到之后**直接沿用**，不要另起一套（两套协议并存＝必然混乱）。

## E 组 · ★ **"你这辈子怎么走到今天的"**（不是物件，但一样是材料）

> **这一组是 2026-09-27 加进来的。** 原 18 类几乎全是**"物件"**——
> 文件、照片、本子、仓库。于是三个被采集者身上各有一批东西**没有任何一类装得下**：
>
> | 被漏掉的东西 | 它决定什么 |
> |---|---|
> | **工作履历**（18岁进电子厂 2 年 → 服务员 → 收银 → 值班经理 → 29 岁当店长，管 11 人） | 第 2 类只在"有简历"时成立，而**没有简历的人恰恰是履历最需要口述的人** |
> | **职业处境**（劳务派遣 / 到手 3800 / "过渡一下"这话说了两年） | 直接影响阶段 3 的载体选型和阶段 6 的状态面板指标 |
> | **说话方式**（把"我"说成"咱"、方言、语速、爱用什么词） | **L3 人设包像不像本人，一半靠这个**——写进提示词才知道该用什么语气 |
> | **关系与日常**（异地两年的对象、8 岁的女儿、带她长大的婆婆） | 陪伴类产品的"24 小时彩蛋""该不该主动说话"全靠它 |
> | **身心状态**（刷题到十二点、焦虑到失眠） | 感知层与护屏方向的依据 |
>
> **共同点**：它们**不是文件**，所以只看文件系统的采集**永远不会发现**——
> 和 C2 组的三类是同一个机理（"会跑采集的人天然只看文件系统"），只是漏得更彻底。
>
> ⚠️ **问法要求**：这两类**必须口述**，不要试图找文件。
> 也不要追问亲密关系的细节（见 `references/1-采集与访谈.md` 的问法准则 4）——**问到"有/大概什么样"就够**。

### 20. 职业轨迹 / 做事史

**例子**：干过哪些活（含**没写进简历的**：厂里、店里、帮人干过的）、**怎么一步步走到现在的**、
上学与培训经历、以及**现在的真实处境**（在职 / 待业 / 过渡 / 备考 / 兼职，收入大概什么水平）。

> 记录的是一条**时间线**：**什么时候 → 干了什么 → 为什么换**。
> ★ **没有简历的人也要问**——实测里有人"这辈子没写过简历"，
> 于是她 15 年的职业轨迹**在清单里一个字都没有位置**，而那是她最硬的一条材料。
> ★ **"现在做什么"不等于"职业"**：备考、带娃、跑长途的家属、
> "过渡一下"说了两年的临时工作——**都算**。

### 21. 关系 / 说话方式 / 身心状态

**例子**：
- **关系**：家里有谁、跟谁最亲、每天要打交道的人、**正在维系的一段关系**（不必说细节）
- **说话方式**：习惯用语与口头禅（例：把"我"说成"咱"）、方言、语速、爱用的比喻
- **作息与节律**：典型一天怎么过（工作日/周末分开）、几点睡几点起、**越不体面越好用**
- **身心状态**：最近累不累、有没有长期焦虑或失眠、什么会让他放松
- **在乎什么**：最近一年最放不下的一件事

> ★ **说话方式这一条最容易被跳过，也最不该跳**——
> 它是**唯一一条能让 AI"像他"的口语材料**。采不到就只能用通用语气，而通用语气
> 正是"这不像我"的主要来源之一（见铁律一）。
> ★ 采法：**把他原话里的口头禅直接记下来**，不要转写成书面语。
> ★ **身心状态涉及隐私**：只问"大概什么样"，**他不展开就不追**，标「未采集」即可。

## ⑲ 反向确认（**不许省**）

勾完上面 21 类之后，**一定要再问这一句**：

> **「上面这 21 类之外，你手上还有什么是这个清单没提到的？哪怕你觉得不相关也可以说。」**

**为什么必须问**：清单是有副作用的——**你列了 N 项，他就只想到 N 项**，清单本身会变成新的天花板。
他补的每一条**都要加回这份清单**，下一个使用者就多一类可勾。

> ★ **加回清单是一个动作，不是一句感想**：勾完当场就要有人（采集者）把它记进
> `素材台账` 的「清单外补充」栏，并在**本轮收尾时**决定它进不进清单。
> **实测教训**：有一次采集挖出了一条全新的类（"按年整理的相册"），
> 写进了台账、也写进了观测记录，**但清单本身至今仍是 20 类、没有它**——
> **"记住了"和"回写了"是两件事，中间必须有人真的去改文件。**

> **这份清单自己就是这么长出来的**：第一版只有 10 类，作者拿真实样本反向审计了一遍，
> 才发现"情报流""作品/交付物""讲过的东西""自己写的工具""旧备份"这几类根本没列——**而那个人全都有。**

### ★ 五个角度：**默认流程，不是备选**

> ⚠️ **这一节的地位在 2026-09-27 被改了。** 原先它写在"**如果他说想不起来**"底下，
> 等于备选方案。**实测把这个权重证伪了：**
>
> | 问法 | 实测产出 |
> |---|---|
> | **原句**「20 类之外还有什么」 | **0 条**（被采集者原话：「想不起来了……我觉得该说的都说了吧」） |
> | **五个角度** | **全部新增都在这儿** |
>
> **所以：原句照问（它是开场，成本一句话），但不论他答什么，五个角度都要走一遍。**
> 清单是按**材料的种类**问的；角度是按**回忆的入口**问——**走的是不同的记忆通路**。
> **原句是开场白，角度才是引擎。**

照这五条**每条都要问**（不是"想不起来才问"）：

| 角度 | 问法 |
|---|---|
| **时间** | 你**跨时间重复做过**、因而留下记录的事有哪些？（长期打卡 / 早年但现在停了 / 某段特别密后来断了 / 按年按学期的计划总结 / **按年整理的东西**） |
| **空间** | **不在"这台电脑上"**、但确实是你的东西有哪些？（纸质本子 / 手机里的 / 实物或照片 / 多个硬盘网盘 / **别的城市、老家、出租屋里的**） |
| **他人** | 关于「**别人眼里的你**」，你手上有哪些？（评价反馈 / 聊天记录里你自己说过的话 / 你为别人做的东西 / 别人给你的东西） |
| **情绪** | 那些**你不太主动拿出来、但确实存在**的东西有哪些？（写过不想给人看的 / 买了没坚持的 / 反复纠结没结论的 / 避着不愿谈的） |
| **工具** | 你**每天真正在用的**工具有哪些？（含手写、纸质、手机 app——不只是电脑上的） |

> **实测效果**：拿真实的人跑这几个角度，**当场挖出原清单完全没有的东西**
> （"不在电脑上的东西""别人眼里的你""放弃与纠结清单"三类就是这么来的，
> 以及"**按年整理的相册**"——这一条连 20 类都装不下）。
> **所以角度不是备选方案，它是清单的第二套引擎。**
>
> ★ **顺序注意**：**别把这五条预先列给他看**。实测里有人把它当"第二份清单"一次性发出去，
> 那就失去了"换记忆通路"的作用——**它是口头的追问，一次一条。**

## 台账（勾完立刻落盘，不要只留在对话里）

存成 `素材台账-YYYY-MM-DD.md`：

```markdown
# 素材台账（YYYY-MM-DD）

| # | 类别 | 有/没有/不确定 | 在哪（路径 / 软件） | 最后更新 | 备注 |
|---|---|---|---|---|---|
| 1 | 深度访谈 | ✅ | | | |
| 2 | 既有材料 | ✅ | | | |
| … | | | | | |
| 13 | 不在电脑上的东西 | ✅ | | | 纸质本子未数字化 |
| 14 | 别人眼里的你 | ✅ | | | 含他人反馈，注意隐私边界 |
| 16 | 旧物/舍不得扔的东西 | ✅ | | | **带年份的优先记** |
| 17 | 旧版本/废弃副本 | ⚠️ 有 | | | **权威版本 = ？待判定** |
| 20 | 职业轨迹/做事史 | ✅ | | | 口述，非文件 |
| 21 | 关系/说话方式/身心状态 | ✅ | | | 口述；口头禅要记原字 |

> **每行后面加一栏 `他的答法`**：`主动说出 / 我问了才说 / 追问才说 / 说没有`。
> ⚠️ **这一栏比勾没勾上更要紧**，但**必须如实**——
> 实测里有一次 6 行标了"追问才说"，核对后发现**只有 1 行真的有对应的追问回合**，
> 其余是他在同一轮里自己接出来的。**"没追问"就写"没追问"，别为了好看贴上"追问才说"。**
```
